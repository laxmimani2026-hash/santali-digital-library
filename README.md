# Santali Digital Library

Modern E-Book Publishing Platform for Santali, Odia, Hindi, and English Literature.

## 🚀 Free Hosting Instructions

### Option 1: Firebase Hosting (Recommended)
1. Install Firebase CLI: `npm install -g firebase-tools`
2. Login to Firebase: `firebase login`
3. Initialize project: `firebase init hosting`
4. Choose existing project or create new one.
5. Set `public` as public directory.
6. Run `firebase deploy`

### Option 2: GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Select branch `main` and folder `/public` (or root if configured).
4. Click **Save** to launch website for FREE!
